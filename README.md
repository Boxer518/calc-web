# Калькулятор и конвертер

Веб-приложение на Flutter: главная, калькулятор, конвертер валют и отдельные экраны результата. Состояние расчёта живёт в адресе страницы, поэтому ссылку можно открыть сразу, без заполнения формы.

## Запуск

Нужен Flutter 3.38 или новее (в задании `go_router` 17.5).

```bash
flutter pub get
flutter run -d chrome --web-port=5555
```

Проверки из задания:

```bash
flutter analyze
flutter test
flutter build web
```

Адрес без решётки включает `usePathUrlStrategy()`. Встроенный сервер `flutter run` отдаёт `index.html` на любой путь, поэтому обновление страницы и прямой переход не сбрасывают приложение на главную.

## Экраны

- Главная — переход к калькулятору и конвертеру.
- Калькулятор — два числа и операция `+`, `-`, `*`, `/`. Пустое поле и нечисловой ввод остаются на форме.
- Конвертер — шесть валют (RUB, USD, EUR, CNY, GBP, JPY) и сумма. Курсы заданы константами в `lib/logic/currency.dart`: сколько рублей стоит одна единица.
- Результат — отдельная страница. Считает заново из параметров адреса и показывает либо число, либо текст ошибки.
- Неизвестный адрес, например `/qwerty`, открывает экран 404.

Кнопка темы в правом верхнем углу переключает светлое и тёмное оформление. Выбор, как и последняя пара валют, сохраняется между перезагрузками.

Формы ограничены по ширине и остаются читаемыми от 360 до 1920 пикселей.

## Схема маршрутов

| Адрес | Экран |
| --- | --- |
| `/` | Главная |
| `/calculator` | Форма калькулятора |
| `/calculator/result?a&op&b` | Результат вычисления |
| `/converter` | Форма конвертера |
| `/converter/result?amount&from&to` | Результат конвертации |
| любой другой путь | 404, `errorBuilder` |

Переходы между разделами идут через `context.go`, поэтому адрес в браузере меняется, а кнопка «Назад» возвращает на предыдущий экран приложения.

### Как параметры попадают из формы в адрес и обратно

1. Форма проверяет поля. Если значение пустое или это не число, `context.go` не вызывается.
2. Калькулятор собирает ссылку сам. Операция кодируется через `Uri.encodeComponent`: в строке запроса символ `+` означает пробел, поэтому плюс уходит как `%2B`.

   `/calculator/result?a=10&op=%2F&b=3`

3. `GoRouter` находит вложенный маршрут `result` и читает `state.uri.queryParameters`.
4. Экран результата не получает готовое число. Он вызывает `calculate` или `convert` по параметрам из адреса.
5. Тот же разбор выполняется, если адрес введён вручную или открыт в новой вкладке. Отсюда же обрабатываются деление на ноль, нечисловые значения, неизвестная операция, неизвестная валюта и отсутствующий параметр.
6. Число на экране округляется до шести знаков после запятой, хвостовые нули убираются: `10 / 3` выглядит как `3.333333`.

Кнопка «Вернуться к форме» снова вызывает `context.go` на `/calculator` или `/converter`.
